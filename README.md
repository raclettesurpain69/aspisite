# AspiSite

Logiciel Python qui copie un site web complet (HTML, CSS, JS, images...) et crée un fichier zip avec tout.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python aspisite.py
```

Une interface graphique s’ouvre, entrez l’URL du site à copier puis cliquez sur "Copier le site".
