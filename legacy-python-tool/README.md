# AspiSite (legacy)

Logiciel Python qui copie un site web complet (HTML, CSS, JS, images...) et
cree un fichier zip avec tout. Sans rapport avec le projet CallFlow AI a la
racine du repo.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python aspisite.py
```

Une interface graphique s'ouvre, entrez l'URL du site a copier puis cliquez
sur "Copier le site".
